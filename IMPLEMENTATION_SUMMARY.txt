USAGE INSTRUCTIONS:
-------------------

1. Configure your API credentials in jarvis.json:
   - Replace "your_actual_api_key_here" with your real API key
   - Update api_url if using a different provider
   - Adjust model, max_tokens, and temperature as needed

2. Restart the bot to load the new command

3. Use the command:
   - Basic: .jarvis [your question]
   - Reply: Send any message, then reply with .jarvis [your question]

EXAMPLES:
---------
.jarvis What is the capital of Indonesia?
.jarvis Write a short story about robots
.jarvis Translate hello to Japanese

[Reply to message/photo + .jarvis]
